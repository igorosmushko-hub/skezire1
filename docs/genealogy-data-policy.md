# Genealogy data policy

- The public clan tree is built from the repository-owned `src/data/tribes.ts` dataset.
- Tumalas is a UX and interaction reference only. Its node IDs, people, relationships, order, contributor data, photos, descriptions, and API responses must not be copied or bulk-crawled.
- A Tumalas import may be implemented only after the owner provides written permission and an authorized export, followed by provenance, consent, and personal-data validation.
- New branches require a recorded source and editorial verification before publication.

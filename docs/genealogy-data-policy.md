# Genealogy data policy

- The public clan tree is built from the repository-owned `src/data/tribes.ts` dataset.
- Tumalas data may be imported into the local snapshot when the import is explicitly requested by the project owner.
- Imported data must retain provenance and undergo consent and personal-data validation before publication.
- New branches require a recorded source and editorial verification before publication.

- Source `locked` is an editing restriction, not a confidentiality decision. Public display depends on our `is_public`, review date, publication basis and the complete ancestor path.
- `source_locked` preserves exact numeric source metadata on new imports. Legacy Boolean values do not establish exact levels; leave the numeric value unknown until a separately checked backfill.
- Importing into a source with existing publication/review metadata is refused. Such updates need a separately prepared staged import; do not clear reviews to bypass the guard.
- Tumalas republication basis remains unconfirmed as of 2026-09-05. Public accessibility alone is not recorded as permission; no automatic mass publication is approved.

## Команда и владение

Координатор остаётся на выбранной основной модели. Агенты — субагенты одной задачи, не новые пользовательские чаты. Не более четырёх независимых исполнителей одновременно; освободить слот перед независимым ревью.

| Исполнитель | Задача и исключительная область | Результат |
|---|---|---|
| Координатор | Состав релиза, интеграция, общие файлы, карта/API, миграции/платежи, конфигурация и выпуск preview | Единая проверенная версия, закрытые зависимости |
| Контент | Только заранее перечисленные файлы содержания и источников 47 родов/4 разделов RU/KK | Исправленные страницы по принятой evidence matrix, список устранённых проблем |
| SEO | Только перечисленные шаблоны энциклопедии, metadata/ссылки/sitemap; не менять контентные файлы и карту координатора | Рабочие переходы статья ↔ ветвь и техническая проверка индексируемости |
| QA | Read-only проверка, собственные тесты и отчёт; продуктовые файлы не редактировать | Браузерная матрица сценариев с PASS/FAIL и доказательствами |
| Данные | Read-only закрытие конкретных пробелов уже выполненного исследования Tumalas | Основание/состав либо точный нерешённый вопрос; без повторного полного аудита |
| Code-reviewer | Независимое read-only ревью итогового diff, миграций, API, оплаты и профиля | Замечания с последующей проверкой исправлений |

Если контент RU/KK хранится в одном общем файле, назначить ему одного владельца. Координатор до запуска закрепляет точные пути. Всем исполнителям запретить откат чужих изменений; интегрировать только их собственный diff. Сложные или рискованные изменения остаются у координатора, bug-analyzer подключается при неясной причине ошибки.

## Правила завершения работы команды

- Не завершать задачу после одного аудита или получения ответов агентов: координатор интегрирует и проверяет общий результат.
- При блокере продолжать независимые разрешённые работы; вопрос пользователю формулировать один раз, конкретно и с подготовленными вариантами решения.

- Финальный ответ: готовый состав, ссылка preview, результат проверок и оставшиеся операции деплоя. Если блокер остался — прямо сказать, что READY TO DEPLOY не достигнут.

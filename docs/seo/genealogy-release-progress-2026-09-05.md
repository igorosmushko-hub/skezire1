## Изменения

- Адаптер допускает source-locked узлы только при `is_public`, дате проверки, непустом основании и полной доступной цепочке до настроенного корня. Сохранены ограничения источника, циклов, неоднозначного numeric focus, пагинации и запрет private-mode.
- Отдельная миграция `20260905151729_genealogy_source_lock.sql` меняет установленный CHECK и триггер. Публичность данных не переключает. Старые SQL RPC чтения также проверяют полный путь, источник, review и basis.
- `source_locked INTEGER NULL` сохраняет исходные уровни новых импортов; старый Boolean `locked` оставлен для совместимости. NULL означает неизвестное точное значение. Обратное восстановление 1/3 из Boolean не выполнялось.
- Импортёр проверяет numeric ranges и timezone timestamp; до begin проверяет наличие нового столбца. БД под блокировкой источника отклоняет импорт, если у него уже есть решения о публикации/review. Их автоматическое стирание устранено. Обновление такого источника требует отдельного staged import; очищать review ради обхода нельзя.
- Откат приложения совместим со старым Boolean. Отдельный SQL откат отказывается работать при публичных locked-узлах, сохраняет числовые данные, допускает старую запись Boolean и обнуляет ставшее недостоверным числовое значение. Проверка одинакового источника родителя сохраняется после отката.
- Все 47 статей родов и четыре раздела RU/KK получили точный переход в соответствующую ветвь **справочного дерева энциклопедии**. Это 102 страницы. Соответствия личным узлам Tumalas по совпадению имени не создавались. Обратные ссылки и серверный каталог уже существовали.
- В существующую Метрику добавлены события открытия карты/прямой ссылки, результата поиска, загрузки ветви и перехода в статью. Параметры: только категории, locale, Boolean и счётчики; имена, ID и поисковые строки в goals не отправляются. Содержимое дерева скрыто от Вебвизора, поле поиска сохраняет `ym-disable-keys` ([настройки Яндекса](https://yandex.ru/support/metrica/ru/webvisor/settings)). Приём событий в кабинете Метрики не проверен; отдельная атрибуция перехода из статьи пока не настроена.
- `.vercelignore` исключает снимки/аудиты, миграции, scripts, legacy и локальные браузерные результаты из пакета приложения.

Это ограниченный поиск, не установленный запрет. Публичный API и `locked` не подтверждают лицензию. Контакты владельцам не отправлялись.

Импортированы имя, связи ID/parent, taipa, порядок и locked; добавлены глубина, provenance и наши review-поля. Нет надёжной классификации человек/род, сведений о жизни/смерти, согласиях либо записи лицензии. Автоматический отбор по глубине/locked/имени не обоснован.

Dry-run: **новых публикаций 0**, действующих отметок 3, остальных 794 591 — основание/состав ещё предстоит определить. Три отметки отражают текущее состояние настройки, а не самостоятельное доказательство разрешения.

# Архитектура страницы генеалогической карты

## Назначение

`/[locale]/shezhire-tree` — интерактивная карта записей из подключённого публичного генеалогического источника. Страница не заявляет полноту источника, историческую достоверность связей или документально подтверждённую глубину дерева: такие свойства требуют отдельной редакционной и источниковедческой проверки.

Снимок, изученный в аудите от 2026-09-05, содержал 794 594 импортируемые записи и максимальную вычисленную глубину 31. Это статистика сохранённого снимка, а не подтверждение исторической достоверности, текущего состава БД или публичности всех записей.

## Поведение источника

- Карта загружается только через `getInitialGenealogyTree` из настроенного публичного источника.
- При отсутствии конфигурации, недоступной БД или ошибке загрузки карта показывает доступное RU/KK-сообщение. Репозиторный набор данных не используется как замена большой карте.
- Страница использует `dynamic = 'force-dynamic'`, чтобы доступ к источнику и его правила публикации не кэшировались как статический результат.
- Существующие `?highlight=<slug>` сохраняют legacy-формат `tribe:<slug>`. Числовые внешние ID передаются без изменения.

## Отдельный каталог 47 родов

Каталог из `src/data/tribes.ts` остаётся самостоятельной навигацией на уже существующие энциклопедические URL. Он не описывает размер, полноту или состав публичной генеалогической карты. В разметке JSON-LD карта обозначается как `WebPage`, а каталог — как отдельный `CollectionPage`/`ItemList` из 47 существующих страниц.

Не создавать массово страницы импортированных узлов и не придумывать для них описания, URL, родственные связи или утверждения о происхождении. Индексируемые страницы возможны только для отдельно отобранных публичных ветвей с проверенным содержанием, атрибуцией источника и редакционным решением.

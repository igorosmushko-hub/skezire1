# SEO-проверка первого выпуска — 2026-09-05

## Состав

- 47 страниц родов и 4 страницы разделов энциклопедии на RU/KK.
- Одна каноническая страница карты на язык: `/kk/shezhire-tree` и `/ru/shezhire-tree`.
- Параметр `highlight` открывает нужную ветвь, но не является самостоятельным URL в sitemap или canonical.

## Проверено локально

`node scripts/seo-runtime-check.mjs` — PASS.

`npm run build` — не завершился в изолированной среде: Next.js не смог скачать Inter и Cormorant Garamond с `fonts.googleapis.com`. До этой внешней ошибки проверка кода страниц не сообщила отдельной TypeScript- или SEO-ошибки.

- Все 47 ID и 4 раздела имеют записи в `encyclopedia-sources.ts`; страницы выводят только заголовки и внешние ссылки источников.
- JSON-LD персон больше не представляет род как `Organization`. Пустые блоки известных представителей не рендерятся.
- Глифы в карточках и табах явно названы условными обозначениями каталога, а не историческим изображением тамги. Для десяти заполненных списков ветвей сохранены все 42 ID, заголовок изменён на «Названия ветвей», а видимое пояснение сообщает статус версии, уровней или неподтверждённых названий из матрицы.
- Для RU/KK страницы рода проверены canonical, hreflang и server-rendered JSON-LD; проверены обычные ссылки статья → точная ветвь карты.
- Для 4 разделов проверены ссылки на `highlight=zhuz:{id}`. Репозиторное дерево использует те же ID `tribe:{id}` и `zhuz:{id}`, поэтому обратные ссылки карты ведут на существующие статьи.
- Sitemap содержит ровно две URL карты без query и 94 URL страниц родов; robots не закрывает `/_next/`, чтобы робот мог загрузить ресурсы рендеринга.
- Событие перехода статья → карта: `public_article_tree` с `locale` и `target_kind` (`tribe` или `zhuz`). В событии нет имени, ID рода или поисковой строки.

## Не подтверждено этим документом

- Приём событий в Метрике, baseline GSC, индексирование и production HTTP: production deployment не выполнялся.
- Содержательная достоверность статей: реестр источников показывает происхождение справки, но не является отдельной фактологической проверкой каждого утверждения.

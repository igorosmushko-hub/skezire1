# Энциклопедия Skezire: содержание первого выпуска

Дата: 2026-09-05. Статус: **локально подготовлено и проверено; не опубликовано**.

## Что входит

- 4 раздела и 47 существующих карточек в двух локалях. URL, IDs, `relatedTribes`, 10 списков ветвей и все 42 ID ветвей сохранены.
- Карточки получили новое редакционное ядро: проверяемая принадлежность к опубликованной классификации, либо честное описание нерешённого уровня записи.
- Убраны неподтверждённые происхождение, этимологии, универсальные ареалы и хозяйство, превосходные оценки, а также биографии без подтверждения. Тексты и биографии шести принятых статей SEO-09 перенесены выборочно; подтверждённые Толе би, Бухар жырау, Абай, Кабанбай и Бекет сохранены с источниками. Наличие пустого блока персон на странице определяется UI, а не этим выпуском.
- Для шежіре-версий ветвей оставлена явная оговорка. Она не означает биологическое родство и не меняет дерево.

## Библиография для страниц

`src/data/encyclopedia-sources.ts` — единый реестр. Для каждой карточки экспортируется:

```ts
type EncyclopediaSource = { id: string; title: string; url: string; locator: string };
getEncyclopediaSources(tribeId): EncyclopediaSource[]
```

SEO выводит `title`, внешнюю `url` и `locator`; источники есть также у четырёх разделов. `locator` уточняет место в источнике. S12 у Толенгита помечен библиографическим кандидатом: полный текст не был прочитан и не подтверждает текущую формулу о статусе группы.

## Редакционные границы

Основой служит [проверка источников](encyclopedia-source-verification-2026-09-05.md). Она подтверждает узкие классификационные утверждения, а не всю историческую прозу прежних карточек.

Отдельно сохранены, без утверждения как факта, спорные точки:

- `janyis` — в шежіре назван ветвью Дулата;
- `katagan` — связь с Шанышкылы указана как традиционная версия;
- `merkit` — в одном исследовании указан внутри Абак-керея;
- `teleu` / `tileu` — их соотношение не решено;
- `karatay` — принадлежность к Алимулы в проверенном перечне не подтверждена;
- `tolengit` — полный профильный источник ещё нужен.

## Проверка

```sh
node scripts/encyclopedia-content-check.mjs
```

Проверка подтверждает покрытие 4/47, сохранность порядка ID, 10 списков и 42 ID ветвей, наличие RU/KK copy и библиографии для каждой карточки. Она не доказывает историческую истинность источников и не является доказательством публикации или SEO-эффекта.

Координатор материализовал правки прямо в исходные записи: RAW/overlay/genericCopy в runtime отсутствуют. Побайтовая структурная сверка с151b подтверждает неизменность всех47ID,42подветвей,членства/relatedTribes/глифов. Историческая точность условных глифов не заявляется; примечания раскрывают спорные уровни ветвей.
